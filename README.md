# Allenamento

Web app (PWA) per il piano di allenamento: turni, sessioni, timer di recupero, corsa e acqua.
Funziona anche offline e i dati restano salvati sul telefono.

## Installarla su iPhone

1. Apri il sito pubblicato con **Safari**.
2. Tocca **Condividi** → **Aggiungi alla schermata Home** → **Aggiungi**.
3. Apri l'app dall'icona: si avvia a schermo intero, come un'app normale.
